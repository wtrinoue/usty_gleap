# 🎮 Ustyゲーム開発
ゲームでよくある「やられちゃった」の概念を覆したお墓を駆使した2D見下ろし型アクションゲームを開発！完成次第UnityRoomに投稿予定
# 🔥 ゲーム開発計画 (2026後期開発)
## 目標「迷わない、世界観がわかる」
- Player、敵、エフェクトにアニメーション
- お墓、アイテムにイラスト
- ステージ作成
- PlayerのステータスUI
- 操作方法UI
# 🔧 開発環境
- **Engine**: ```Unity 6000.2.6f2```
- **Platform**: WebGL
- **Version管理**: Git / GitHub Desktop
- **タスク管理**: issues / Discord 

# 📐 編集ルール
- Membersフォルダーの自分のフォルダーでは**追加・削除・変更**が自由にできます。
- Membersフォルダー以外は、**参照**なら可能です。
- オブジェクトやアセットなどで細かいところで変更して使いたいときにはコピーして自分のファイルに持ってきて使ってください。（後で統合します。）
  - Prefabをコピーして持ってくる。
  - ScriptableObjectを自分のフォルダーで作成する。
  - etc...

**プロジェクトが大きくなっているので相談しながら臨機応変に編集します。**
